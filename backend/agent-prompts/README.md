# Agent Prompts

This folder explains the AI prompts used by the greenhouse server. The live prompt builders currently live next to the feature that uses them so developers can read the data query and prompt together.

- `autopilot.md` explains the AI autopilot prompt and safety rules.
- `camera-diagnosis.md` explains the plant photo diagnosis prompt.
- `insights.md` explains dashboard AI analysis prompts such as forecasts, root cause, experiments, and hardware checks.
