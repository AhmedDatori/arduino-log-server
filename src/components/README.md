# Components

Components are reusable interface blocks used by one or more views.

- `Header.jsx` renders the top navigation and Smart Green House brand.
- `DeviceBar.jsx` shows connection, latest reading count, and active plant.
- `SensorCard.jsx` renders sensor gauges and number cards.
- `ControlCard.jsx` renders actuator toggle cards.
- `ModeSelector.jsx` switches between manual, rules, and AI autopilot modes.
- `AutopilotStatus.jsx` shows recent autopilot decisions.
- `HealthScore.jsx` shows the AI health score panel.
- `PredictionCard.jsx` shows stress forecasts.
- `SensorFusionCard.jsx` explains combined sensor meaning.
- `HardwarePanel.jsx` shows hardware diagnostics.

Files ending in `.css` style the component with the same name.
