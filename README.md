# Smart Green House Server

This server powers the Smart Green House dashboard, stores ESP32 sensor logs, receives ESP32-CAM frames, controls actuators, and runs optional AI analysis.

## Main Commands

```bash
npm install
npm run check:backend
npm run build
npm start
```

## Required Configuration

Create deployment environment variables based on `.env.example`. For local development, you can also create a `.env` file in this folder.
For hosting setup, read `HOSTING_ENV.md`.

Required for database startup:
- `DATABASE_URL`, or `PGHOST`, `PGUSER`, and `PGPASSWORD`.

Optional for AI features:
- `GEMINI_API_KEY`.

## Folder Guide

- `server.js` starts the app.
- `backend/` contains the Express backend, database setup, routes, services, jobs, and AI prompt documentation.
- `src/` contains the React Smart Green House dashboard.
- `dist/` is generated by `npm run build`.

For a plain-English backend map, read `backend/README.md` and `backend/ROUTE_MAP.md`.
